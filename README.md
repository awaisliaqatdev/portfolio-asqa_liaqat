# Dr. Aqsa Liaqat — Portfolio Website

A premium, fully responsive medical professional portfolio built with React, Tailwind CSS, and Framer Motion.

## Tech Stack

- **React 19** — UI framework
- **Vite** — Build tool & dev server
- **Tailwind CSS v4** — Utility-first styling
- **Framer Motion** — Animations
- **Lucide React** — Icons

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Project Structure

```
src/
  components/
    ui/          # Reusable UI components (Button, Card, Badge, SectionHeader)
    layout/      # Navbar, Footer
  sections/      # Page sections (Hero, About, Education, etc.)
  data/          # Content data
  hooks/         # Custom React hooks
  utils/         # Helper utilities
  App.jsx        # Root component
  main.jsx       # Entry point
  index.css      # Global styles & Tailwind config
```

## Features

- Fully responsive (mobile to ultra-wide)
- Scroll spy navigation
- Smooth animations with Framer Motion
- Glassmorphism effects
- Accessible (WCAG compliant)
- SEO optimized
- Zero console warnings
